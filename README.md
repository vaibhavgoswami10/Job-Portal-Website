# Job Portal Website

Welcome to the Job Portal Website project! This is a full-featured platform where users can apply for jobs and employers can post job vacancies. It's designed to streamline the hiring process and make it easier for job seekers and companies to connect.



## 🚀 Features

- 🧑‍💼 **Job Seekers**:
  - Browse available job listings
  - Apply for jobs with a resume and cover letter
  - Create and manage profiles

- 🏢 **Employers**:
  - Post new job vacancies
  - Manage existing listings
  - View and review applications from candidates

- 🔐 **Authentication**:
  - Secure sign-up/login system for both job seekers and employers

- 📋 **Dashboard**:
  - Separate user-friendly dashboards for job seekers and employers
